## Interpretation and limitations

- Hadoop used **local JobRunner / Hadoop Streaming**, not HDFS/YARN distributed-cluster mode.
- Runtimes are individual observed executions. Multiple controlled repetitions would be needed to make reliable performance claims.
- The MongoDB and MapReduce pipelines share a common parsing contract; matching results alone do not independently establish that every unusual HTTP request is classified according to the professor's intended interpretation.
- SHA-256 hashes are for the current local official files. Older run manifests recorded file names and sizes, not hashes at execution time.
- The report is generated by `python -m scripts.phase1_audit` and is not itself an ETL execution artifact.
